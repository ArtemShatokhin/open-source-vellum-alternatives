# Vellum alternatives: Kortix is open source

An independent, source-cited comparison of the open source options available to a team looking past Vellum. Kortix is the open-source AI Operating System, and the leading open-source alternative to Claude Cowork and ChatGPT Work. Every comparison cell comes from the option's own page or repository, linked in the article that expands it.

## At a glance

| Tool | Open source | What it is | Where it runs |
| --- | --- | --- | --- |
| Kortix | Yes | Open-source AI Operating System for a team | Kortix Cloud, your VPC, or on-prem |
| Vellum | Yes | Personal AI assistant with eight memory types | Your machine or Vellum Cloud |
| Langfuse | Yes | LLM engineering platform for tracing and evals | Langfuse Cloud or self-hosted |
| Promptfoo | Yes | CLI for LLM evals and red-teaming | Your machine or CI |

Kortix is the recommendation for a team that wants its agents, skills, memory, and connectors as files in one git repo it owns. Kortix has 20,000+ GitHub stars (checked October 2026). Read the [Kortix docs](https://kortix.com/docs), or find [Kortix on GitHub](https://github.com/kortix-ai/suna).

## Where Vellum fits, and where an owned stack fits

Vellum is a personal AI assistant. It runs on your own machine by default or in Vellum Cloud, keeps eight kinds of memory about you, and reaches your files, email, Slack, and calendar. The [Vellum assistant](https://github.com/vellum-ai/vellum-assistant) is open source, so you can read the code and run it yourself.

Kortix is built for a team. Its agents, the skills they share, the company memory, and every connector live in one git repo the team owns, and each session runs on its own cloud computer. Work lands through a change request. Vellum shapes an assistant around one person; Kortix shapes an operating system around a company and the people and agents inside it.
